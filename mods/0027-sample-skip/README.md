# 0027-sample-skip

**The sample layer skips voices that would only make silence**

| | |
|---|---|
| status | `built` |
| in the default build | yes |
| registry claims | 1 cave, 2 detour, 1 patch |

## What it does and how

0x4011c64c, the stock sample layer, resamples and filters all 8 physical voices
every audio block whether or not a sample plays: 15% of a block on the unit
(meter, 2026-11-13), unchanged with every sample off. For a voice whose filter
state (12 longs at +44 of its 92-byte struct) is zero and whose input samples
the resampler would read are all zero, both stages give exact zeros: the
resampler is skipped and the voice's position advanced as it would have been,
the filter is skipped and its output buffer zeroed for the stock level ramp.
What you hear does not change; only work whose result is zero is skipped. The
DMA bookkeeping between the stages always runs.

Code in cave32, FUNC. GEN.'s (machine 43, hidden) main routine; its
dispatch-table entry is pointed at DISABLE. The routine's helpers after it
(0x40114394..) stay: other code calls them.
